# How Long Would YOU Last in a Caveman's World? — видео №7

Факты сверены по источникам:
- исследование сна хадза: Samson et al. 2017;
- мозоли у тех, кто ходит босиком, примерно на 30% толще, а чувствительность ступни не хуже: Holowka et al. 2019, Nature;

- Shanidar 1: материалы Смитсоновского института;
- пиковая скорость Usain Bolt — 44,72 км/ч;
- у черепов до появления земледелия кариес встречается заметно реже.
