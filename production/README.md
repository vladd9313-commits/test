## Монтаж из своих картинок

Назовите картинки по порядку промптов (`1.png`, `2.png`, … `603.png` — подойдут любые имена, которые сортируются по номеру) и запустите:

```bash
python3 tools/montage.py --images /путь/к/картинкам --out final_video.mp4
# с фоновой музыкой:
python3 tools/montage.py --images /путь/к/картинкам --music music.mp3 --music-volume 0.07
```

N-я картинка встаёт на N-ю строку сценария, склейка — ровно на начале фразы, в каждом кадре лёгкий зум или панорама.

## Пересобрать озвучку (например, другим голосом)

```bash
python3 tools/make_voiceover.py <папка с kokoro-v1.0.onnx и voices-v1.0.bin> <папка вывода> am_michael 0.93
```

## Кадры в стиле Paint без нейросети

```bash
python3 tools/paint_frames.py <папка для кадров>      # 603 кадра 1920x1080
python3 tools/montage.py --images <папка для кадров> --crf 33
```
Когда появятся картинки из нейросети по `image_prompts.txt`, достаточно перезапустить `montage.py` с их папкой.
